# Rusch-Lockhart Manor

**Architectural Vision Document**

An interactive architectural planning document for a modern contemporary estate featuring:

- 🏠 **Main House**: 4,200 sq ft single-story modern design
- 🏡 **Guest House**: 800 sq ft detached ADU
- 💼 **Office/Gym Building**: 600 sq ft productivity sanctuary
- 🚗 **3-Car Garage**: 900 sq ft
- 🌳 **Recommended Land**: 2-3 acres

## Features

- **Interactive Site Plan** — Compound layout with all buildings and outdoor spaces
- **Detailed Floor Plans** — Room-by-room layouts with dimensions (tabbed interface)
- **Design Direction** — Visual concepts for modern contemporary aesthetic
- **Cost Calculator** — Toggle between Standard, Custom, and Luxury finish levels
- **Project Timeline** — Phased approach mapped to a 3-5 year build timeline

## Hosting on GitHub Pages

1. Push this repository to GitHub
2. Go to **Settings** → **Pages**
3. Under "Source", select **Deploy from a branch**
4. Choose **main** branch and **/ (root)** folder
5. Click **Save**
6. Your site will be live at `https://[your-username].github.io/rusch-lockhart-manor/`
